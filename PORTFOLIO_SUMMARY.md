# Portfolio listing

## Queensland Road Safety Investment Prioritisation

- **Category:** Data analysis / decision intelligence
- **Tools:** Python, SQL, SQLite, dimensional modelling, data quality, Chart.js, Power BI design
- **Live project:** https://didi-au.github.io/queensland-road-safety-analytics/
- **Repository:** https://github.com/didi-au/queensland-road-safety-analytics

I built a reproducible analytics pipeline and decision dashboard over 415,407 Queensland road-crash records. The analysis showed why absolute and resident-normalised serious-injury burden must be treated as separate prioritisation questions, then converted that evidence into a two-track investment recommendation. The repository demonstrates API ingestion, dimensional modelling, advanced SQL, automated data-quality controls, executive communication and explicit analytical limitations.

**Suggested portfolio-card text:**

> End-to-end Queensland road-safety analysis using Python, SQL and official open data. Models 415,407 crashes, tests data quality, and recommends separate high-volume program and regional diagnostic funding tracks through a live decision dashboard.
